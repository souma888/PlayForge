# Diorama material atlas

`diorama-materials.webp` is an original generated base-color atlas, produced with the
built-in image generation tool for this project. It contains blue slate rock, weathered
limestone masonry, terracotta gravel and mossy forest ground in four quadrants. The
scene applies it to actual 3D geometry, rather than using a concept image as a backdrop.

Prompt brief: a square four-quadrant PBR base-color atlas, orthographic flat diffuse
surfaces without cast shadows, perspective, objects, gaps or labels; dark slate-blue
fractured mountain rock with small ochre veins; aged light-gray limestone blocks in
offset courses; terracotta sandstone gravel; olive forest ground with pine needles,
scree and moss. Crisp photographic grain at multiple scales.
